# Module 11 — Execution & Live Loop (L11)

## Purpose
Bridge from analysis to action across three gated maturity stages:
- **Stage S1**: Manual (System alerts via Telegram -> operator clicks on exchange).
- **Stage S2**: Semi-auto on Binance testnet (Freqtrade or CCXT bot).
- **Stage S3**: Live auto-execution with micro-capital.

## Key Rule
- **No-card-no-trade law**: Trading without an active Edge Card is a protocol violation. 3 violations in a week triggers a mandatory system lockout.
