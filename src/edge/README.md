# Module 6 — Edge Analytics Engine (L6)

## Purpose
Answer with statistical honesty: "When, where, and under what conditions does each strategy actually make money?" and package results as actionable Edge Cards.

## Key Capabilities
- **Slice Statistics**: Calculate $n$, expectancy ($R$ & bps), win rate, profit factor, bootstrap CIs.
- **Dimension Scans**: Auto-loop over `(hour x day)`, `(session x regime)`, `(month)`, etc.
- **Significance Layer**: Benjamini-Hochberg FDR correction ($q=0.05$) and both-halves in-sample stability requirement.
- **Edge Card Generator**: Outputs validated operational cards with explicit expiry.
