# Module 10 — Command Center UI (L10)

## Purpose
One screen where you operate the system. The UI's job is decision compression.

## 7 Standard Pages
1. **Page 1 — Overview**: Daily operational screen, equity curve, active Edge Cards, risk status.
2. **Page 2 — Miner Control**: Launch mining runs, live progress, survivor leaderboard.
3. **Page 3 — Edge Explorer**: Slicing & filtering panel, heatmaps, BH significance badges.
4. **Page 4 — Validation Center**: Walk-forward folds, Monte Carlo cloud, PBO & DSR scores.
5. **Page 5 — Portfolio**: Current HRP weights, correlation heatmap, dendrogram.
6. **Page 6 — Trade Journal**: Filterable trade table, pre-trade checklist, emotion score.
7. **Page 7 — Data & System Manager**: Pair x timeframe coverage matrix, gap report, scheduler status.
